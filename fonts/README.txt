TAN MERIGUE — where to put the font files
=========================================

TAN MERIGUE is a commercial typeface (TAN Type Foundry). It is not
included here because it has to be licensed and downloaded by you.

Once you have your licensed copy, drop the file(s) into THIS folder
using exactly these names:

    TANMERIGUE.woff2      <- best option, smallest + fastest
    TANMERIGUE.woff
    TANMERIGUE.ttf
    TANMERIGUE.otf

Any one of them is enough; the CSS tries them in that order.
No code changes needed — css/style.css already points here.

If you only have a .ttf or .otf, you can convert it to .woff2 for
free at https://transfonter.org or https://cloudconvert.com so the
site loads faster.

Until a file is present, those headings fall back to Bricolage
Grotesque and everything still looks fine.

Where TAN MERIGUE is used:
  - P O R T F O L I O  (hero)
  - ABOUT / BACKGROUND / CAPABILITIES / PROJECTS section labels
  - the "Languages" heading
  - "PROJECT 01 / 05" and "NEXT PROJECT" on project pages
